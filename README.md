# ViT-B/16 Classification Pipeline

DIMER inference wrapper for **`timm/vit_base_patch16_224.orig_in21k_ft_in1k`** — ImageNet-1k image classification (1000 classes) — pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot.

## Upstream alignment

- Model: `timm/vit_base_patch16_224.orig_in21k_ft_in1k`
- Revision: `e0bd370de6799e8d1f47a911174ff4c3708e2323`
- Upstream weight license: Apache-2.0
- Upstream task: image classification, 1000 ImageNet-1k classes, fixed 3×224×224 input (16×16 patches, CLS-token pooling); ImageNet-21k pretraining → ImageNet-1k fine-tune per the pinned upstream README; 86.6 M parameters
- Repository adaptation: bounded supervised adaptation on `{id, image, label}` records (`adapt`) — a new linear head on the frozen 768-d pre-logits (frozen policy) and an optional unfreeze of the last transformer blocks selected against it by validation log-loss (unfrozen policy) — measured by held-out accuracy and macro-F1 (`evaluate`, `knn_baseline`, `majority_baseline`); `predict` and the ImageNet-1k head are unchanged; the base weights are never redistributed and the adapter is a tutorial output

## Quick start

```python
from PIL import Image
from vit_classification_pipeline import ViTClassificationPipeline, top_k_accuracy

pipe = ViTClassificationPipeline.from_pretrained()          # cuda:0 if available, else cpu
result = pipe.predict(Image.open("photo.jpg"), top_k=5)
print(result["predictions"][0]["predicted_label"], result["predictions"][0]["top_k"][0]["score"])
print(top_k_accuracy(result["predictions"], [targets_index], k=1))

# adaptation: the pinned iNaturalist bird photographs (fetched and digest-checked at run time), floors, two policies
from vit_classification_pipeline import fetch_sample_dataset

splits = fetch_sample_dataset()                                   # 108 / 24 / 48 {id, image, label} records, 6 species
print(pipe.knn_baseline(splits["train"], splits["test"])["accuracy"])   # frozen pre-logits, no training
pipe.adapt(splits["train"], splits["validation"], trainable_blocks=0)   # frozen policy: linear probe
print(pipe.evaluate(splits["test"])["accuracy"])
pipe.adapt(splits["train"], splits["validation"])                     # unfrozen policy: last two blocks, selected on validation
print(pipe.adapter["policy"], pipe.evaluate(splits["test"])["accuracy"])
print(pipe.classify(splits["test"][0]["image"])["labels"])           # the new six-way head; predict() still answers in ImageNet-1k
pipe.save_artifact("outputs/vit_adapter")                         # adapter.safetensors + manifest.json
reloaded = ViTClassificationPipeline.from_artifact("outputs/vit_adapter")
```

`score` is a softmax score over 1000 classes, not a calibrated probability; the reported label is the argmax. Every image is resized (shorter side 248 px) and center-cropped to the checkpoint's fixed 224×224 input (`crop_pct 0.9`, bicubic, mean/std 0.5); there is no dynamic-resolution path.

## Weights layout

```
weights/vit-base-p16-224/
  dimer-base-manifest.json   # modelId, revision, per-file bytes + sha256 (verified on every load)
  config.json                # timm pretrained_cfg: input size, mean/std, crop
  model.safetensors          # 346284714 bytes, git-ignored
weights/inat-birds/          # git-ignored run-time cache of the 180 pinned CC0 photographs (19 MB)
```

`from_pretrained()` calls `verify_snapshot()` first and refuses to load if any file is missing or its SHA-256 differs from the manifest. Without a snapshot, `allow_download=True` loads from the Hub through timm's `hf-hub:timm/vit_base_patch16_224.orig_in21k_ft_in1k@e0bd370de6799e8d1f47a911174ff4c3708e2323` form; the default is to refuse. To stage the snapshot: `hf download timm/vit_base_patch16_224.orig_in21k_ft_in1k --revision e0bd370de6799e8d1f47a911174ff4c3708e2323 --local-dir weights/vit-base-p16-224`, then write the manifest.

Its default path stages the missing `model.safetensors` with `stage_missing_files(..., allow_download=True)` and digest-verifies the snapshot, fetches the 180 digest-pinned CC0 iNaturalist photographs and draws 108 / 24 / 48 images by a seeded stratified split with `validate_dataset`, `check_split_disjoint` and `observer_overlap`, classifies three photographs of the exposed development test through the ImageNet-1k inference contract (three of the six species have no ImageNet-1k class), scores the frozen 768-d pre-logits on that exposed split by a majority floor, a cosine 5-NN vote and a new six-way linear probe (the frozen policy; 5-NN 75.0 %, probe 79.2 % in the 2026-10-09 run), runs the pre-registered validation grid (C0 / C1 / C2, `docs/vit-preregistration.md` and amendment 1) and reloads the selected config (the 2026-10-18 T4 evaluation of record selected C1, as the masked CPU check did), scores a fresh observer-disjoint 96-photograph test only under the pre-registered settings (observer-cluster bootstrap verdict; in the 2026-10-18 evaluation of record the adapted C1 did not beat the frozen probe: 81.25 % against 83.33 %, CI [−0.0632, 0.0204], `no detectable difference`), prints predictions before and after, and exports the new head plus any trained blocks as a safetensors adapter that reloads to identical probabilities and identical `predict` output. Seven `outputs/` entries are written (`…_train.csv`, `…_input_manifest.json`, `…_grid.json`, and `…_evaluation_report`, `…_predictions`, `…_adapter`, `…_result` with a look suffix: none for the first pre-registered evaluation, `_reproduction_<n>`, `_exploratory_<n>` or `_masked_<n>` otherwise); BYOD refusals stop with one `RunStopped` message. BYOD (a `.zip` with `labels.csv` beside the image files) is optional and gated off by default.
